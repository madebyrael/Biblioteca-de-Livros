## Projeto Biblioteca

## 1. Funcionalidades
- Cadastrar Livros;
- Registrar Usuário;
- Histórico de Livros com registro se está disponível ou reservado;
- Histórico de Usuários;
- Realizar Empréstimos;
- Devolver Livros;
- Histórico de Livros Registrados(Livro, usuário e data de empréstimo);

## 2. Entidades
- Livro;
- Usuário;
- Empréstimo;
- Busca Histórico de Livros;
- Busca Histórico de Usuários;
- Busca Histórico de Livros Reservados;

## 3. Regras do Programa
- Um livro só pode ser registrado uma vez;
- Um usuário só pode ser cadastrado uma vez;
- Um usuário só pode pegar um livro por vez;
- Não é possível pegar emprestado um livro que já está em mãos de algum usuário;
